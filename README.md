# Overview

This project focuses on Credit Risk Analysis and Loan Default Prediction using the LendingClub Loan Dataset. The goal is to analyze borrower behavior, identify financial risk patterns, and build machine learning models capable of predicting whether a loan is likely to default.

The project combines:

- Exploratory Data Analysis (EDA)
- Data preprocessing and feature engineering
- Classification models
- Regression models
- Clustering techniques
- Model evaluation and comparison

This work was developed as part of the Distributed Data Analysis and Mining (DDAM) course in the Master's Program in Data Science and Business Informatics.
